# Classification recordings

These archives contain the three supplied classification session exports. Each archive preserves the session folder, its `emg.jsonl`, `vision.jsonl`, `events.jsonl`, `metadata.json`, and `manifest.json` files. Finder metadata files such as `.DS_Store` were excluded.

- `classification1.zip`
- `classification2.zip`
- `classification3.zip`

The recordings are raw EMG and camera-derived landmark/movement data. Extract an archive to inspect its JSONL files or use the research recorder's session import workflow where available.
